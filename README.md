# My agent skills

Personal agent preferences, maintained separately from third-party skills.

## Installed skill

`my-typescript-preferences` applies my TSX conditional rendering conventions alongside general TypeScript guidance.

## Local setup

The global skill locations link to `skills/my-typescript-preferences` in this checkout. Edit the source here, then commit and push to back it up. Changes are available through the links without copying files.

Third-party `npx skills update -g` updates use their own tracked sources. Keep this personal skill's unique name and do not replace it with a third-party skill.

On another computer, clone this private repository and link `skills/my-typescript-preferences` into `~/.agents/skills/` and, when using a separate Codex home, `$CODEX_HOME/skills/`.
